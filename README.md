# Student Fun Zone

Vanilla HTML/CSS + Angular aplikacija sa trackerima i mini-igrama.

## Funkcionalnosti

### Trackeri
- **Water Tracker** - Praćenje dnevnog unosa vode sa sedmičnom statistikom (Chart.js)
- **Sleep Tracker** - Praćenje sna
- **Budget Tracker** - Praćenje troškova
- **Reading Tracker** - Praćenje pročitanih stranica i knjiga
- **Focus Tracker** - Praćenje fokusiranog rada
- **Calendar Tracker** - Organizacija i planiranje aktivnosti

### Igre
- **Kanban Board** - Organizacija zadataka
- **Whiteboard** - Digitalna tabla za bilješke
- **Vision Board** - Vizualizacija ciljeva
- **Bingo** - Interaktivna igra
- **Quiz** - Edukativni kvizovi


## Tehnologije

- **Angular 21** - Frontend framework
- **Firebase** - Authentication & Firestore baza podataka
- **Chart.js** - Vizualizacija podataka i statistike


## Instalacija i pokretanje

```bash
# Instalacija zavisnosti
npm install

# Pokretanje development servera
npm start
# ili
ng serve
```

Aplikacija će biti dostupna na `http://localhost:4200/`
